# TEKY Learning Hub – Documentation

Tài liệu thiết kế, kiến trúc và đặc tả kỹ thuật cho dự án TEKY Learning Hub (SEP490_FA26_TEKY-Learning-Hub).

## Cấu trúc thư mục

- `architecture/`: Sơ đồ kiến trúc Clean Architecture, C4 model, Flow biểu đồ nghiệp vụ.
- `database/`: Thiết kế cơ sở dữ liệu, ERD diagram, Data dictionary, Migration guide.
- `api/`: Tài liệu API specs, Postman Collection, Swagger contracts (/api/portal/* và /api/admin/*).
